# Practical Marketing Strategy for UMKM Through Social Media

Interactive HTML Presentation Deck presented at **Crayon 2026** by **Adhi Baskoro** (Digital Ads Specialist di DMO Marcomm Telkomsel Area Jawa Bali).

---

## 📋 Deskripsi Proyek

Slide presentasi interaktif responsif 16:9 (1920x1080) yang membahas strategi pemasaran digital praktis untuk UMKM lewat media sosial:
1. **Practical Marketing & Branding Strategy** (Brand Identity, Positioning, Content Strategy 70/20/10, Funnel)
2. **Business Reality & Experience** (Insight Industri, Studi Kasus UMKM, Common Mistakes)
3. **Digital Platforms & Tools Solutions** (Instagram, TikTok, Google Maps, WhatsApp Business, Action Plan 30 Hari)

---

## 🎮 Kontrol & Shortcut Keyboard

| Tombol / Aksi | Fungsi |
| --- | --- |
| `→` / `↓` / `Space` / `Enter` | Maju ke slide / step animasi berikutnya |
| `←` / `↑` / `Backspace` | Kembali ke slide / step sebelumnya |
| `F` | Toggle Mode Layar Penuh (Fullscreen) |
| `N` | Toggle Catatan Pembicara (Speaker Notes) |
| `Home` / `End` | Langsung ke slide pertama / terakhir |
| Swipe Kiri / Kanan | Navigasi sentuh (Mobile & Tablet) |
| Tombol UI di bawah | Navigasi Prev/Next, Nomor Slide, Notes, Fullscreen |

---

## 🚀 Menjalankan Secara Lokal

Cukup jalankan server lokal sederhana:

```bash
# Menggunakan Node / npx
npx serve .

# Atau menggunakan Python
python3 -m http.server 8000
```

Buka peramban di `http://localhost:8000`.

## 🌐 Deploy ke Vercel

Proyek ini telah dikonfigurasi dengan `vercel.json` dan siap di-deploy langsung ke Vercel dengan **0 konfigurasi**:

1. Masuk ke [vercel.com](https://vercel.com).
2. Klik **Add New...** > **Project**.
3. Hubungkan akun GitHub Anda (`adhibasworkspace`) dan pilih repositori `practical-marketing-strategy-umkm`.
4. Klik **Deploy**.
5. Situs presentasi akan otomatis online dan dapat diakses dengan domain `.vercel.app`.
